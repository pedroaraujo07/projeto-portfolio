# Projeto Portfólio

Projeto de um portfólio pessoal desenvolvido com **HTML5 e CSS3**, criado com o objetivo de apresentar informações sobre minha formação, habilidades e projetos desenvolvidos durante meus estudos em Engenharia de Software.

O projeto também foi utilizado para praticar conceitos importantes de desenvolvimento web, com destaque para **Flexbox, CSS Grid e responsividade**.

## Sobre o projeto

O portfólio apresenta informações sobre minha trajetória como estudante de Engenharia de Software, minhas principais habilidades, formação acadêmica e alguns dos projetos que desenvolvi.

A estrutura foi construída buscando uma organização simples, visualmente agradável e adaptável a diferentes tamanhos de tela.

Entre os conteúdos apresentados estão:

* Informações pessoais e apresentação profissional;
* Habilidades técnicas e pessoais;
* Formação acadêmica;
* Projetos desenvolvidos;
* Links para acessar os projetos;
* Layout responsivo para diferentes dispositivos.

## Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Visual Studio Code

## Conceitos praticados

Durante o desenvolvimento do projeto, foram trabalhados principalmente:

* Estruturação semântica com HTML5;
* Organização de elementos utilizando **Flexbox**;
* Construção de layouts utilizando **CSS Grid**;
* Responsividade para diferentes tamanhos de tela;
* Utilização de Media Queries;
* Organização e estilização de componentes com CSS;
* Criação de uma interface voltada para apresentação profissional.

## Responsividade

O portfólio foi desenvolvido para se adaptar a diferentes dispositivos e resoluções, permitindo que o conteúdo seja apresentado de forma adequada em computadores, tablets e celulares.

O uso combinado de **Flexbox, Grid Layout e Media Queries** permite reorganizar os elementos da página conforme o tamanho disponível da tela.

## Objetivo

O principal objetivo deste projeto foi desenvolver meu próprio portfólio enquanto praticava conceitos fundamentais de desenvolvimento front-end.

Além de servir como uma página para apresentar meus projetos, o desenvolvimento também contribuiu para aprimorar meus conhecimentos em **HTML, CSS, Flexbox, Grid Layout e desenvolvimento responsivo**.
